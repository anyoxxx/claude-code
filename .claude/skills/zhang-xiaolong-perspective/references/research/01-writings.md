调研对象：张小龙（Zhang Xiaolong / Allen Zhang），Foxmail创始人、微信创始人、腾讯高级执行副总裁

**⚠️ 重要消歧**：网络上存在同名人物「张小龙」（粉笔教育CEO，2026年因人大讲座言论争议辞任）。本调研严格排除一切与该教育公司高管相关的信息，只聚焦微信/Foxmail创始人张小龙。

## 一、核心著作/长文

张小龙本人**没有出版过系统性著作**（不同于芒格《穷查理宝典》式的书）。他最重要的"系统性思考"载体是历年的长篇演讲，后被媒体整理成文字稿广泛流传：

### 1.《微信背后的产品观》（2012年8小时20分内部演讲）
- 2012年7月24日，腾讯大讲堂，14:20—23:30，现场1700余人
- 内容来自他"15年产品心得"，据称源于日常用手机记录的300余条笔记，整理为180余页PPT
- 后整理为同名图书《微信背后的产品观》（豆瓣可查，非张本人执笔出版，为演讲整理稿）
- 核心论点（据CSDN/虎嗅整理稿摘要）：
  - "有趣高于功能，功能高于交互，交互高于UI"
  - "需求不来自调研、不来自分析、不来自讨论、不来自竞争对手，需求只来自你对用户的了解"
  - "没有设计，只有解决问题"
  - "爽、好玩胜过功能"
  - "做3秒就能想明白怎么用的功能，需要文字解释的功能就要重新设计"
- 来源：[CSDN整理稿](https://blog.csdn.net/weixin_41337483/article/details/114493975)、[虎嗅](https://m.huxiu.com/article/2067.html)、[豆瓣书目](https://book.douban.com/subject/35339729/) — 二手转载/整理，原始来源为张本人演讲（一手言论，二手记录/传播渠道）

### 2. 历年"微信公开课Pro"主题演讲（2016–2021，年度）
这是张小龙最系统的公开思考载体，性质接近"年度产品哲学随笔"：

| 年份 | 主题/要点 |
|------|----------|
| 2016 | 首次公开演讲，提出微信四大价值观（见下） |
| 2017 | 小程序发布前夕的公开阐述 |
| 2018 | "每天5亿人吐槽，1亿人教我做产品" |
| 2019 | 4小时演讲，约3万字，回应"微信变老""封闭"质疑，谈小程序、小游戏、社交、AI、阅读 |
| 2021 | "微信十年的产品思考"，主题词为"连接"与"简单" |
| 2022起 | 张小龙本人缺席微信公开课主论坛，改由各业务线负责人分享（视频号、支付、小程序等），此后（2023、2024、2025）延续闭门+缺席模式 |

来源：[数英3万字实录整理](https://www.digitaling.com/articles/96207.html)、[凤凰网2021实录](https://tech.ifeng.com/c/83AXIiPvEZB)、[极客公园"7个逻辑和一个选择"](https://www.geekpark.net/news/272954)、[搜狐2022公开课报道](https://www.sohu.com/a/514778237_115565)、[财经/一财2024闭门报道](https://m.yicai.com/news/101954484.html) — 均为二手媒体整理稿转述张本人一手演讲内容

### 3. 微信四大价值观（2016年首次公开演讲提出，反复被引用）
1. 一切以用户价值为依归
2. 让创造发挥价值
3. 好的产品是用完即走的
4. 让商业存在于无形之中

来源：[极客公园](https://www.geekpark.net/news/214442)、[第一财经](https://www.yicai.com/news/4737150.html)、[腾讯大学](https://daxue.qq.com/content/content/id/2321) — 多个权威媒体交叉复现，可信度高，判定为**反复出现≥3次的核心论点**，符合"真信念"标准

### 4. 饭否（fanfou）2010–2012年约2350条微博体日记
非严格意义上的"著作"，但属于持续两年、体量巨大的个人化系统性表达，主题横跨产品、社交、人性。**这部分内容更适合归入表达DNA（03）维度**，此处仅记录其存在与规模：2351/2359条（不同信源统计数字略有出入），时间跨度2010年11月26日—2012年4月9日。来源：多篇整理帖（Medium/CSDN转载），**原始饭否平台已停运，无法核对原文**，转载准确性无法完全验证。

## 二、反复出现的核心论点（≥3次复现，判定为真信念候选）

1. **"用完即走"（好的产品用完即走）** —— 2016年首次提出，此后多年反复引用；后因公众误解而补充"走了还会回来"。见 [界面新闻](https://www.jiemian.com/article/1041249.html)
2. **"克制"是外界贴的标签，非本人自我定位** —— 张小龙本人明确表示"'克制'这个词从来没有在我脑袋里出现过"，他认为自己追求的是"理性"而非刻意"克制"。这是一个**重要的自我认知 vs 外部标签的矛盾点**，详见04他者视角。来源：[界面新闻](https://www.jiemian.com/article/1041249.html)
3. **产品经理"上帝视角"/生物进化类比** —— 产品经理应像"上帝"一样制定简单规则，让群体在系统内自我演化；"上帝制定简单规则，然后让世界自我演化"。多次在不同场合（2012演讲、后续访谈）复现。来源：CSDN/腾讯云整理稿（[腾讯云](https://cloud.tencent.com/developer/article/1070200)、[数英"没有产品只有人性"](https://www.digitaling.com/articles/1026171.html)）
4. **"善良比聪明更重要"**（引用贝索斯语，但被张反复引用并内化为微信产品价值观）—— "欺骗用户是最容易做的事，因为只需要聪明就可以了"。来源：多篇媒体整理稿，2016年首次公开演讲即提出
5. **拒绝白名单/特权** —— "白名单是系统的瑕疵"，认为好的规则应该是普适的系统能力而非给少数人开后门。与"用简单规则支撑群体自演化"的模型一脉相承
6. **需求来自对人性的洞察，不来自调研/竞对/讨论** —— 2012年演讲反复强调的方法论核心

## 三、自创术语/概念

- **"用完即走"** —— 广为流传但也被误解的标签性短语，后来他不得不亲自补充"走了还会回来"来纠偏，说明这个短语的公众传播已经脱离了他的本意（值得在诚实边界/张力中记录）
- **"上帝视角"做产品** —— 将产品经理工作类比为"造物主设定简单规则、让群体自我演化"
- **微信四大价值观**（见上）—— 非严格意义的自创术语，更像是他系统化提炼出的一套原则清单
